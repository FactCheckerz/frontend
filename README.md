# 🔎 Fact Checker

> **Understand what’s true. Verify what you see.**

**Fact Checker** is an AI-powered multimodal application that helps users verify information from **text, audio, and video**.

The system identifies the claims present in the provided content and evaluates them against available evidence. Users receive a simple, easy-to-understand result for each claim.

### ✨ What it provides

* 📝 **Claim Detection** — Identifies factual claims from the input
* ✅ **Verdict** — Supported, Refuted, or Insufficient Evidence
* 📊 **Confidence Score** — Shows the system's confidence
* 💡 **Explanation** — Explains the reasoning behind the result
* 🔗 **Evidence** — Provides relevant supporting or contradicting sources

### 🧩 Project Flow

```text
Text • Audio • Video
        ↓
   Claim Detection
        ↓
   Fact Verification
        ↓
 Verdict + Confidence
        ↓
 Evidence & Explanation
```

---

## 📁 This Repository

This repository contains the **frontend codebase** of Fact Checker, built with **Next.js**.

It provides the user-facing interface for submitting content and viewing the resulting claims, verdicts, confidence scores, explanations, and evidence.

The **backend is maintained separately** and handles the core AI-powered analysis. Both components work together to deliver the complete fact-checking experience.
